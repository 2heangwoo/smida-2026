상명대학교 스페이스디자인 졸업전시 도록 - 웹 플립북

[빠른 테스트]
1. 이 폴더에서 간단한 웹서버를 실행합니다.
   Windows: START_DEMO.bat 더블클릭
2. 브라우저가 열리면 demo.html로 12페이지 샘플을 확인할 수 있습니다.

[전체 208페이지 사용]
1. 원본 PDF를 이 폴더에 복사합니다.
2. 파일명을 book.pdf 로 바꿉니다.
3. START_FULL.bat 를 실행합니다.
4. 홈페이지 서버에 올릴 때는 index.html, style.css, app.js, book.pdf를 같은 폴더에 업로드하면 됩니다.

[중요]
- PDF를 파일 탐색기에서 index.html로 직접 열면 브라우저 보안 정책 때문에 PDF 로딩이 차단될 수 있습니다.
- 반드시 웹서버(http/https)에서 여십시오.
- 본 뷰어는 현재 보이는 페이지 중심으로만 렌더링하므로 208페이지 대용량 PDF도 메모리 부담이 작습니다.
- 서버가 HTTP Range 요청을 지원하면 PDF.js가 필요한 부분을 나눠 받아 초기 로딩을 줄입니다.

[조작]
- 좌우 페이지 가장자리 클릭
- 키보드 ← / →
- 확대/축소 버튼
- 전체화면
- 모바일에서는 1페이지 보기로 자동 전환
