상명대학교 스페이스디자인 제36회 졸업전시 - 웹 플립북 (수정본)

이 버전은 PDF.js/CDN을 사용하지 않습니다.
원본 208페이지 PDF를 웹용 JPEG 페이지로 변환해 두었으므로 인터넷 연결 없이도 바로 열립니다.

[실행]
1. 압축을 모두 풉니다.
2. START.bat를 더블클릭합니다.
   또는 index.html을 직접 더블클릭해도 됩니다.

[조작]
- 좌/우 화면 가장자리 클릭
- 키보드 왼쪽/오른쪽 방향키
- 상단 이전/다음 버튼
- p. 입력칸으로 페이지 바로 이동
- 확대/축소/맞춤/전체화면
- 모바일에서는 자동 1페이지 보기

[홈페이지에 게시]
폴더 구조를 그대로 서버에 업로드하면 됩니다.
  index.html
  style.css
  app.js
  pages/page-001.jpg ... page-208.jpg

외부 라이브러리나 CDN에 의존하지 않기 때문에, 기존 버전처럼 'PDF 불러오는 중…'에서 멈추는 문제가 없습니다.
